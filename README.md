# 🔍 Python Port & Recon Scanner

A lightweight, automated Python script built for target asset mapping during security assessments and Bug Bounty reconnaissance.

## 🚀 Features
- **DNS Resolution:** Automatically resolves domain names to IPv4 addresses.
- **High-Risk Port Scanning:** Checks critical infrastructure ports including:
  - Remote Access (SSH, FTP)
  - Web Services (HTTP, HTTPS, 8080, 8443)
  - Databases & Caches (MySQL, PostgreSQL, Redis)
- **Timeout Management:** Implements non-blocking socket timeouts for fast scanning.
